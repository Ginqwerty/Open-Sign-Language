# Site

A static, read-only view of the papers, datasets and leaderboards in this repository. It reads `data/*.json` (generated by `scripts/parse.py`), so it has no build step and no dependencies. Nothing in `README.md` or `helper/` is changed by it.

## Preview locally

The page loads JSON with `fetch`, so open it through a local web server rather than as a file:

```bash
python3 -m http.server 8000     # run from the repository root
# then open http://localhost:8000/site/
```

## Publish with GitHub Pages

Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` / `(root)`. The site is then served at `https://<owner>.github.io/<repo>/site/`. The empty `.nojekyll` file at the repository root makes Pages serve the files as they are.

## Keeping it current

The site shows whatever is in `data/*.json`. After editing `README.md` or `helper/datasets.md`, run `python3 scripts/parse.py` and `python3 scripts/lint.py` (see `docs/maintaining.md`) and commit the result; the site needs no other change.

## Notes

- Every entry links back to its line in `README.md` or `helper/datasets.md`; those files stay the source of truth.
- Paper topics (recognition, translation, production, ...) are inferred from the README heading an entry sits under, not stored in the data.
- Only `http` and `https` links are rendered. A link written without a scheme in the source (for example `github.com/user/repo`) is opened with `https://`.
- Leaderboard numbers are copied from the original papers and not re-run.
- Text from the data is inserted with `textContent`, never as HTML.
